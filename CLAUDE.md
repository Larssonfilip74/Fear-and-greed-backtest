## Project
Pre-registered, look-ahead-free research. The question: does the CNN Fear & Greed index (F&G) give an executable
edge for **long-only, long-horizon ES1! futures positions** (NQ1! is used only for frozen-rule validation)?

The user's choices:
- discover the strategy from the data;
- long-only first (shorts only with explicit approval);
- no stop-losses;
- orders only in the US cash session (RTH);
- TradingView Essential/Plus.

`RESEARCH_PROTOCOL.md` is **approved and frozen**. Amendments go in its amendment log (A1 exists) with reason and date.
`DATA.md` holds the data sources, known data issues and the TradingView export checklist.

## Non-negotiable rules (details in the protocol)
- **R1 timing:** F&G(d) is usable from 00:00 UTC d+1. The earliest fill is the next NYSE RTH open (`fgbt.data.align`).
- **Splits** (`fgbt.splits`):
  - DEV 2011–2020;
  - VAL 2021-02 → 2024-12;
  - **HOLDOUT 2025-01-01 → 2026-09-30 is locked.** Always go through `research_view`, which raises `HoldoutLockedError`.
    It is unlocked once, at the final gate (P7).
- Every evaluated configuration is logged with `fgbt.validation.trial_registry.log_trial`, because the trial count feeds DSR and PBO.
- **Statistics:**
  - judge results per event, with independent episodes (at least 20 false sessions between them);
  - HAC standard errors;
  - stationary bootstrap;
  - a null-preserving AR(1) bootstrap for predictive tests (Stambaugh bias);
  - Holm correction per hypothesis family;
  - final candidates must pass DSR, PBO (via CSCV) and SPA.
- **Verdicts:** ACCEPT / PROVISIONAL / REJECT. Fewer than 30 events caps a result at PROVISIONAL. "No edge" is a valid result.
- Raw data is never edited. Every raw file goes in `data/raw/*/MANIFEST.json` with its SHA-256.
