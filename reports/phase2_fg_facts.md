Rule of thumb for event tests: with n independent events and a per-event return sd of σ, the smallest mean effect detectable at 5% (two-sided, 80% power) is ≈ 2.8·σ/√n. With n = 20 that is ≈ 0.63σ. Any configuration with < 30 events is capped at PROVISIONAL (protocol §8).
